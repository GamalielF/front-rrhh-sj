1. Instalar [pnpm](https://pnpm.io/installation)

2. Clonar el [repo](https://github.com/BlassGO/sanjose-workspace)

3. Instalar dependencias:
   ```bash
   pnpm install --frozen-lockfile
   pnpm install -g @angular/cli
   ```
