description: Comandos disponibles para gestionar proyectos en el workspace.
---

Comandos disponibles:

| Comando | Descripción |
| --- | --- |
| `pnpm new nombre-del-proyecto` | Crea un nuevo proyecto |
| `pnpm delete nombre-del-proyecto` | Elimina un proyecto |
| `pnpm register nombre-del-proyecto` | Solo registra el proyecto en el workspace (sin crearlo) |

:::note
Estos comandos modifican `angular.json`, `package.json` y `tsconfig.app.json`.
:::
