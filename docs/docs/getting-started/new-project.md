title: Nuevo proyecto
description: Pasos para crear un nuevo proyecto en el workspace.
---

1. Inicia un nuevo proyecto. Consulta [Gestión de proyectos](./manage-project.md) para más información.


```bash
pnpm new nombre-del-proyecto
```

2. Ejecutalo localmente:

```bash
pnpm start:nombre-del-proyecto
```

:::info
Comandos disponibles:

| Comando | Descripción |
| --- | --- |
| `pnpm start:nombre-del-proyecto` | Inicia el servidor de desarrollo |
| `pnpm build:nombre-del-proyecto` | Compila el proyecto |
:::
