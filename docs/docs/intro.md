## San José Lúmen

Es una librería de servicios y componentes de interfaz de usuario compartidos para agilizar el desarrollo de aplicaciones web de la Cooperativa de Ahorro y Crédito San José. Esta librería está incluida completamente en el workspace Angular, lista para usar sin configuración adicional.

:::info
Aunque se utiliza [Taiga UI](https://taiga-ui.dev/) para los iconos SVG, los componentes no dependen de esta librería.
:::

## Librerías Incluidas

El workspace San José incluye las siguientes librerías:

- **@lumen/auth**: Sistema de autenticación y autorización
- **@lumen/base**: Componentes base y layouts preconfigurados
- **@lumen/http**: Servicio simplificado para peticiones HTTP
- **@lumen/ui**: Componentes UI reutilizables y estilizados
